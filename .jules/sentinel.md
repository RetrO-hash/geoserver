## 2024-05-24 - XML External Entity (XXE) Vulnerability in ReaderUtils
**Vulnerability:** The `DocumentBuilderFactory` and `SAXParserFactory` instances in `org.geoserver.util.ReaderUtils` (`parse` and `validate` methods) were created without disabling Document Type Declarations (DTDs) and external entities. This allows for XML External Entity (XXE) injection attacks if untrusted XML is parsed, leading to local file disclosure, internal port scanning (SSRF), and denial of service.
**Learning:** Even utility methods for parsing basic XML configurations must be explicitly secured against XXE when dealing with instances of `DocumentBuilderFactory` and `SAXParserFactory`. Java's default settings for these parsers are historically insecure.
**Prevention:** Always explicitly configure XML parser factories to disable DTDs (`disallow-doctype-decl`), external general entities, external parameter entities, and `load-external-dtd`. Additionally, for `DocumentBuilderFactory`, ensure `setXIncludeAware(false)` and `setExpandEntityReferences(false)` are set. Wrap configuration in try-catch and throw runtime exceptions securely.
