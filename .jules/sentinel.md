## 2026-05-27 - Fix XXE vulnerability in ReaderUtils

**Vulnerability:** DocumentBuilderFactory and SAXParserFactory in `org.geoserver.util.ReaderUtils` were not properly configured to prevent XML External Entity (XXE) processing. They failed to explicitly disable document type declarations, external general/parameter entities, and loading external DTDs.
**Learning:** When configuring XML parsing factories like DocumentBuilderFactory and SAXParserFactory, setting features (e.g., `setFeature(...)`) must be individually wrapped in try-catch blocks. If they are not, and the parser lacks support for a specific feature, the resulting exception will halt execution, bypassing the remaining secure configurations and leaving the parser vulnerable. Instead of throwing exceptions in the catch blocks, which would still halt execution and bypass the rest, exceptions should be logged so execution continues and attempts to apply the remaining security features (defense in depth).
**Prevention:** Always explicitly configure DocumentBuilderFactory and SAXParserFactory with `setFeature` calls to disable DOCTYPE declarations, external entities, and load-external-dtd, ensuring each `setFeature` call is in an isolated `try-catch` block that securely logs and swallows the exception. Also configure `setXIncludeAware(false)` and `setExpandEntityReferences(false)` for DocumentBuilderFactory.
