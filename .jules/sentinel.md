## 2024-05-26 - [Fix XXE vulnerability in XML parsing]
**Vulnerability:** XML External Entity (XXE) vulnerabilities found in `ReaderUtils.java` across multiple modules. Instances of `DocumentBuilderFactory.newInstance()` and `SAXParserFactory.newInstance()` are missing configuration to disable external entities, external DTDs, and document type declarations. This allowed malicious XML files to fetch arbitrary files or execute Server-Side Request Forgery (SSRF).
**Learning:** Default configuration of Java XML parsers is insecure. Standard utility classes for parsing XML that don't enforce secure configurations become an easy attack vector when untrusted XML gets parsed. We need to disable DTD, external general/parameter entities, and XML includes for both `DocumentBuilderFactory` and `SAXParserFactory`.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` with explicit security settings. Use features like `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd` set to false or true as necessary. For `DocumentBuilderFactory`, also call `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch general exceptions and log them before throwing the expected exceptions to avoid signature regression.
