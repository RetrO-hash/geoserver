## 2026-06-16 - Prevent XXE (XML External Entity) Vulnerabilities in XML Parsers
**Vulnerability:** Found unconfigured `DocumentBuilderFactory` and `SAXParserFactory` instances in `org.geoserver.util.ReaderUtils` that are vulnerable to XML External Entity (XXE) injection attacks when parsing untrusted XML data.
**Learning:** XML parsers must be explicitly configured to disallow DOCTYPE declarations (`http://apache.org/xml/features/disallow-doctype-decl`) or disable fetching of external entities (`external-general-entities`, `external-parameter-entities`, `load-external-dtd`) to prevent unauthorized file access or SSRF via malicious XML payloads. Each security feature needs to be enabled using a `try/catch` block to ensure a failure configuring one feature doesn't prevent configuring the remaining ones.
**Prevention:** Always secure `DocumentBuilderFactory`, `SAXParserFactory`, and `XMLInputFactory` by explicitly disabling DOCTYPE declarations or external entities, and for DOM parsers explicitly calling `setExpandEntityReferences(false)`.
