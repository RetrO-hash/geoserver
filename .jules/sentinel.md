## 2026-04-17 - Fix XXE in ReaderUtils DocumentBuilderFactory and SAXParserFactory
**Vulnerability:** XML External Entity (XXE) vulnerabilities in `ReaderUtils` within the `platform` and `main` modules due to `DocumentBuilderFactory` and `SAXParserFactory` being configured without completely disabling external entity processing.
**Learning:** Even if `setValidating(false)` and `setNamespaceAware(false)` are used, external entities must be explicitly disabled via `setFeature` and `setExpandEntityReferences` or similar controls, as defaults often allow XXE. It's critical to disable DOCTYPE declarations altogether if they aren't needed, or appropriately restrict external general/parameter entities if DOCTYPE is strictly necessary.
**Prevention:** Use secure initialization patterns for all Java XML parsing APIs (DocumentBuilderFactory, SAXParserFactory, XMLInputFactory). Enforce disabling features like `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd`.
