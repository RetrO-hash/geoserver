## 2026-04-14 - Fix XML External Entity (XXE) Vulnerability in ReaderUtils
**Vulnerability:** DocumentBuilderFactory and SAXParserFactory configurations in `org.geoserver.util.ReaderUtils` did not explicitly disable Document Type Definitions (DTDs) and external entities, which exposed the application to XML External Entity (XXE) injection attacks when parsing untrusted XML input.
**Learning:** Java's default XML parser settings in older versions or certain configurations can be vulnerable to XXE. It's necessary to explicitly configure features to disable processing of malicious entities. It's important to configure `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd`.
**Prevention:** Always configure `DocumentBuilderFactory`, `SAXParserFactory`, `XMLInputFactory`, and other XML parsing components to explicitly disable DTDs and external entities whenever possible. Use safe defaults or explicitly turn off unsafe features before parsing XML.
