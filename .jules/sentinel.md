## 2026-04-25 - Prevent XXE Vulnerabilities in XML Parsers
**Vulnerability:** XML External Entity (XXE) vulnerabilities found in `ReaderUtils.java` files within the platform and catalog modules. The `DocumentBuilderFactory` and `SAXParserFactory` instances were used without explicit protections against external entity loading and DTD processing.
**Learning:** Default XML parser configurations in Java are often vulnerable to XXE attacks. Code using `DocumentBuilderFactory` or `SAXParserFactory` must be explicitly configured to prevent resolving external entities and loading external DTDs.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` instances with properties that disable document type declarations, external general/parameter entities, and external DTD loading. For `DocumentBuilderFactory`, also set `XIncludeAware` and `ExpandEntityReferences` to false. Catch configuration exceptions, log them, and fail securely by throwing a `RuntimeException`.
