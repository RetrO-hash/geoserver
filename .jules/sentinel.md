## 2024-05-18 - Prevent XXE Vulnerabilities in XML Parsers
**Vulnerability:** XML parsers (DocumentBuilderFactory, SAXParserFactory) were instantiated without disabling DTDs or external entity processing, leading to potential XML External Entity (XXE) injection attacks when parsing untrusted user input.
**Learning:** Java's default XML parsers are vulnerable to XXE out of the box. They require explicit configuration features ("http://apache.org/xml/features/disallow-doctype-decl", "http://xml.org/sax/features/external-general-entities", "http://xml.org/sax/features/external-parameter-entities", "http://apache.org/xml/features/nonvalidating/load-external-dtd") to safely process XML.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` to disable external entities and DOCTYPE declarations. For `DocumentBuilderFactory`, also call `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch potential configuration exceptions and fail securely.
