## 2024-05-24 - Secure XML Parsing Configuration
**Vulnerability:** XML parsers (like DocumentBuilderFactory and SAXParserFactory) are instantiated without explicit security feature configuration, making them vulnerable to XML External Entity (XXE) injection attacks when processing untrusted XML input.
**Learning:** In Java, default XML parser settings often allow fetching external entities or DTDs, which can lead to information disclosure or Denial of Service (Billion Laughs attack).
**Prevention:** Always explicitly configure `DocumentBuilderFactory`, `SAXParserFactory`, and `XMLInputFactory` with strict security settings: disable external general entities, disable external parameter entities, disable document type declarations (`http://apache.org/xml/features/disallow-doctype-decl`), and set `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Ensure each configuration step is wrapped in its own `try-catch` block so unsupported features do not bypass the remaining security configurations.
