## 2026-04-29 - [CRITICAL] Prevent XXE in RemoteDocumentReaderImpl XML Parsing
**Vulnerability:** XML External Entity (XXE) vulnerability in `RemoteDocumentReaderImpl.java` where `DocumentBuilderFactory` was instantiated without disabling external entities, doctype declarations, and other unsafe XML features. Since this reader accepts arbitrary remote URLs, it is highly susceptible to XXE attacks.
**Learning:** Instantiating `DocumentBuilderFactory.newInstance()` or `SAXParserFactory.newInstance()` leaves default configurations enabled, which typically allow resolving external entities and DTDs. This leads directly to XXE vulnerabilities if an attacker can control the XML being parsed, especially when dealing with remote sources.
**Prevention:** Always explicitly configure `DocumentBuilderFactory` and `SAXParserFactory` using `setFeature` to disable doctype declarations (`http://apache.org/xml/features/disallow-doctype-decl`), external general entities (`http://xml.org/sax/features/external-general-entities`), external parameter entities (`http://xml.org/sax/features/external-parameter-entities`), and load external DTDs (`http://apache.org/xml/features/nonvalidating/load-external-dtd`). Additionally, set `XIncludeAware` and `ExpandEntityReferences` to false for `DocumentBuilderFactory`. Fail securely by catching and wrapping configuration exceptions in a `RuntimeException`.
