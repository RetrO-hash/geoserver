## 2024-06-03 - [XML External Entity (XXE) Vulnerability in ReaderUtils]
**Vulnerability:** DocumentBuilderFactory instances in `org.geoserver.catalog.util.ReaderUtils` and `org.geoserver.util.ReaderUtils` were vulnerable to XML External Entity (XXE) attacks because they lacked the configurations to explicitly disable document type declarations (DOCTYPE) and external entity processing.
**Learning:** XML parsers, especially `DocumentBuilderFactory`, are insecure by default and will process external entities and DOCTYPE definitions. This allows attackers to read arbitrary files from the server's filesystem, cause Denial of Service, or launch Server-Side Request Forgery (SSRF) attacks when parsing untrusted XML inputs.
**Prevention:** Always explicitly disable DOCTYPE declarations (`http://apache.org/xml/features/disallow-doctype-decl`), external general entities (`http://xml.org/sax/features/external-general-entities`), external parameter entities (`http://xml.org/sax/features/external-parameter-entities`), and external DTD loading (`http://apache.org/xml/features/nonvalidating/load-external-dtd`) when using `DocumentBuilderFactory`. Properly catch and log `ParserConfigurationException` and throw a secure runtime exception if configuration fails.
