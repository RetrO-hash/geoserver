## 2026-05-25 - Prevent XXE Vulnerability in SOAP Request Parsing
**Vulnerability:** The `DocumentBuilderFactory` used to parse incoming SOAP requests in `src/ows/src/main/java/org/geoserver/ows/Dispatcher.java` within the `soapReader` method did not have any features set to disable doctype declarations, external entities, or external DTDs, which left it vulnerable to XML External Entity (XXE) attacks.
**Learning:** Even when reading trusted namespaces, XML parsers processing untrusted user input without explicit disabling of features that resolve external entities are susceptible to XXE and SSRF. Specifically in `soapReader`, `dbf.newDocumentBuilder()` is used with data directly from `httpRequest.getInputStream()`.
**Prevention:** Always configure `DocumentBuilderFactory` and other XML parsing factories using the OWASP recommended features (`disallow-doctype-decl`, `external-general-entities`, `external-parameter-entities`, `load-external-dtd`) to explicitly disable external entities before parsing untrusted input. Also ensure XInclude awareness and expanding entity references are set to false. Catch raw `Exception` instances during parsing as `IOException` wrapping may hide deeper configuration failures, and log exceptions with appropriate levels.
