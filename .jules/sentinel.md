## 2026-04-26 - Prevent XXE Vulnerabilities in XML Parsers
**Vulnerability:** Found multiple instances of `DocumentBuilderFactory.newInstance()` being used without disabling external entities. This allows XML External Entity (XXE) attacks, which can lead to local file disclosure, SSRF, or denial of service when parsing untrusted XML input.
**Learning:** Default configurations of Java's `DocumentBuilderFactory` and `SAXParserFactory` are inherently insecure because they resolve external entities by default. This is a common pitfall when parsing dynamic/user-supplied XML.
**Prevention:** Always explicitly disable document type declarations (`http://apache.org/xml/features/disallow-doctype-decl`), external general entities, external parameter entities, and `load-external-dtd`. For `DocumentBuilderFactory`, also explicitly set `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch configuration exceptions, log them, and throw a `RuntimeException` to fail securely.
