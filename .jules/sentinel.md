## 2026-06-20 - [XXE Vulnerability in WPSExecuteTransformer]
**Vulnerability:** DocumentBuilderFactory in WPSExecuteTransformer does not disable DOCTYPE declarations or external entities, leading to XML External Entity (XXE) injection vulnerabilities when parsing untrusted WPS inputs.
**Learning:** When using standard Java XML parsing APIs, features preventing external entity resolution must be explicitly disabled, and each `setFeature` call must be wrapped in a separate try-catch block to ensure that an unsupported feature does not abort the application of subsequent security features.
**Prevention:** Always secure `DocumentBuilderFactory` instances by disabling DOCTYPE declarations (`http://apache.org/xml/features/disallow-doctype-decl`), external general entities (`http://xml.org/sax/features/external-general-entities`), external parameter entities (`http://xml.org/sax/features/external-parameter-entities`), load-external-dtd (`http://apache.org/xml/features/nonvalidating/load-external-dtd`), and explicitly setting `setXIncludeAware(false)` and `setExpandEntityReferences(false)`.
