## 2024-05-17 - Secure DocumentBuilderFactory Configuration for XXE Prevention
**Vulnerability:** DocumentBuilderFactory instances were instantiated without explicitly disabling external entity resolution, external parameter entities, and Document Type Declarations (DTDs). This default configuration allows parsing of maliciously crafted XML files, leading to XML External Entity (XXE) vulnerabilities.
**Learning:** By default, standard Java XML parsers are configured to process external entities and DTDs. To secure them against XXE attacks, developers must explicitly set multiple parser features to false. Catching configuration exceptions individually and failing securely by throwing a checked exception ensures the parser is not instantiated in an insecure state.
**Prevention:** Always secure DocumentBuilderFactory by setting `expandEntityReferences` and `xIncludeAware` to `false`. Explicitly disable the features `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd`. Wrap each setFeature call in an individual try-catch block, logging exceptions securely and failing the operation by throwing an exception matching the method signature.
