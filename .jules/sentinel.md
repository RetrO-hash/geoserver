## 2026-06-09 - XXE Vulnerability in ReaderUtils
**Vulnerability:** XML parsers created using `DocumentBuilderFactory.newInstance()` and `SAXParserFactory.newInstance()` throughout the application are missing configurations to disable XXE (XML External Entity) attacks. An attacker can supply malicious XML that triggers the parser to read local files, execute server-side request forgery (SSRF), or cause denial of service. The `ReaderUtils.parse()` in `src/platform/src/main/java/org/geoserver/util/ReaderUtils.java` and `CapabilitiesXmlReader` are notably affected, but the vulnerability pattern is prevalent.
**Learning:** Default XML parsers in Java are not secure against XXE. `DocumentBuilderFactory` needs specific security features enabled.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` securely by disabling DOCTYPE declarations, external general entities, and external parameter entities. Wrap each `setFeature` call in an individual `try-catch` block to handle exceptions where a feature is unsupported, ensuring the remaining security features are applied.
