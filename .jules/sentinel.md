## 2024-05-15 - Explicit XXE mitigations on DocumentBuilderFactory and SAXParserFactory
**Vulnerability:** DocumentBuilderFactory and SAXParserFactory lack explicit feature configurations to disable external entity resolution and document type declarations, exposing the application to XML External Entity (XXE) vulnerabilities.
**Learning:** Default parsers in Java might implicitly allow processing of DTDs, external general entities, and external parameter entities. Relying on default configurations is insecure. Moreover, when configuring features, wrapping all configurations in a single try-catch or allowing failure on feature setting can leave the parser vulnerable.
**Prevention:** Always instantiate XML factories explicitly disabling DTDs, external general entities, and parameter entities. Each feature should be set inside its own try-catch block to prevent one unsupported feature from halting the configuration of subsequent security features. Additionally, explicitly set XIncludeAware and ExpandEntityReferences to false.
