## 2026-05-29 - Prevent XML External Entity (XXE) in ReaderUtils
**Vulnerability:** Found `DocumentBuilderFactory` initialized without security features to prevent XXE, allowing external entity injection attacks when parsing untrusted XML data.
**Learning:** `ReaderUtils.java` is a core utility class used for parsing XML. Missing features in `DocumentBuilderFactory` create a wide attack surface for XXE across the platform module. Even though `setNamespaceAware(false)` and `setValidating(false)` were set, XXE defenses (like disallow-doctype-decl) were omitted.
**Prevention:** Always explicitly configure `DocumentBuilderFactory` to disable document type declarations (`disallow-doctype-decl`), external general entities, external parameter entities, and external DTDs. Each `setFeature` call must be wrapped in its own `try-catch` block to ensure all supported features are applied even if one fails. Additionally, explicitly configure `setXIncludeAware(false)` and `setExpandEntityReferences(false)`.
