## 2026-04-21 - [Secure XML Parsing configuration to prevent XXE in GeoServer]
**Vulnerability:** XML External Entity (XXE) vulnerabilities in `org.geoserver.util.ReaderUtils`. The utility methods instantiate `DocumentBuilderFactory` and `SAXParserFactory` and allow parsing XML files without disabling external entity processing and document type declarations.
**Learning:** XML parsers must be properly configured to explicitly reject DTDs and external entities (both general and parameter entities). Even if `setValidating(false)` is used, XXE is still possible unless external entity resolution is turned off.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` with the following features set to false: `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, `http://apache.org/xml/features/nonvalidating/load-external-dtd`, and set `http://apache.org/xml/features/disallow-doctype-decl` to true. Catch `Exception` and explicitly throw `RuntimeException` if setting the feature fails.
