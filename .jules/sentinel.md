## 2024-10-24 - [XXE Vulnerability in XML Parsers]
**Vulnerability:** DocumentBuilderFactory, SAXParserFactory, and TransformerFactory instantiations in the codebase are vulnerable to XML External Entity (XXE) injection because they do not disable external entities or document type declarations.
**Learning:** Java XML parsers by default allow external entities, which can lead to information disclosure or Server-Side Request Forgery (SSRF) when parsing untrusted XML.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` with secure settings: disable `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd`. For `DocumentBuilderFactory`, also call `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch configuration exceptions and handle them securely.
