## 2024-05-24 - Secure XML Parsing (XXE) with DocumentBuilderFactory
**Vulnerability:** DocumentBuilderFactory instantiated without disabling DTDs and external entities, making it vulnerable to XXE (XML External Entity) attacks, especially when reading from remote URLs.
**Learning:** By default, XML parsers often resolve external entities. This codebase requires explicitly setting multiple features (`disallow-doctype-decl`, `external-general-entities`, `external-parameter-entities`, `load-external-dtd`) and each `setFeature` call must be wrapped in its own individual `try-catch` block to prevent parsing if the parser configuration fails. Catching generic `Exception` thrown by `setFeature` is necessary.
**Prevention:** Always secure `DocumentBuilderFactory` immediately after instantiation by disabling DTDs, external entities, and setting `XIncludeAware` and `ExpandEntityReferences` to false. Wrap each `setFeature` in an individual `try-catch` block and fail securely.
