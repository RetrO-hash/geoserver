## 2024-06-07 - Fix XXE in ReaderUtils DocumentBuilderFactory and SAXParserFactory
**Vulnerability:** XML External Entity (XXE) vulnerabilities in `org.geoserver.util.ReaderUtils` where `DocumentBuilderFactory` and `SAXParserFactory` were instantiated without explicitly disabling DTDs and external entities.
**Learning:** `DocumentBuilderFactory.newInstance()` and `SAXParserFactory.newInstance()` are vulnerable to XXE by default in older Java versions and some parser implementations. We must explicitly set features to disable DTDs, external general/parameter entities, and load-external-dtd. Each feature must be wrapped in its own try-catch block because if a parser doesn't support a feature, the remaining security features would be skipped if they were in the same try block. For DocumentBuilderFactory, `setXIncludeAware(false)` and `setExpandEntityReferences(false)` should also be called.
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` to disable DTDs (`http://apache.org/xml/features/disallow-doctype-decl`) and external entities. Wrap each `setFeature` call in a separate try-catch block.
