## 2026-03-31 - [CRITICAL] Prevent XXE (XML External Entity) Vulnerabilities in XML Parsers
**Vulnerability:** The application parsed XML using `DocumentBuilderFactory.newInstance()` without explicitly disabling document type declarations and external general entities, potentially allowing XML External Entity (XXE) attacks if the parser was fed malicious XML.
**Learning:** Java's default XML parser behavior resolves external entities. It is essential to explicitly configure `DocumentBuilderFactory` to disable these features to prevent XXE.
**Prevention:** Always configure `DocumentBuilderFactory` with `setFeature("http://apache.org/xml/features/disallow-doctype-decl", true)` and `setFeature("http://xml.org/sax/features/external-general-entities", false)` when parsing potentially untrusted XML. Use try-catch blocks to handle potential `ParserConfigurationException` or `UnsupportedOperationException` for parsers that do not support these features, logging a warning if so.
