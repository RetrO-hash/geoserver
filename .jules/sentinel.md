## 2026-04-16 - Prevent XML External Entity (XXE) Vulnerability in ReaderUtils
**Vulnerability:** The `ReaderUtils.java` utility class, which provides XML parsing methods for GeoServer, used `DocumentBuilderFactory` and `SAXParserFactory` without disabling document type declarations, external general entities, and external parameter entities. This allowed XML External Entity (XXE) attacks, which could lead to sensitive data exposure, SSRF, or denial of service when untrusted XML was processed.
**Learning:** `DocumentBuilderFactory` and `SAXParserFactory` instances must be configured securely by explicitly turning off features that process external entities. `ReaderUtils` had disabled some namespace and validation options, but left default entity resolving behavior active, which is inherently insecure.
**Prevention:** Always secure Java XML parsers (`DocumentBuilderFactory`, `SAXParserFactory`, `XMLInputFactory`, `TransformerFactory`) by setting features such as `http://apache.org/xml/features/disallow-doctype-decl` to `true`, and `http://xml.org/sax/features/external-general-entities` / `http://xml.org/sax/features/external-parameter-entities` to `false`. Catch any parser configuration exceptions, log them securely, and throw a `RuntimeException` to fail securely.
