## 2024-05-18 - Prevent XXE Vulnerability in XML Parsers
**Vulnerability:** XML External Entity (XXE) vulnerability in `RemoteDocumentReaderImpl.java` where `DocumentBuilderFactory` is instantiated without disabling external entity and DTD processing.
**Learning:** Instantiating `DocumentBuilderFactory.newInstance()` without explicitly disabling `disallow-doctype-decl`, `external-general-entities`, `external-parameter-entities`, and `load-external-dtd` allows parsing of malicious XML from user-provided URLs, potentially leading to arbitrary file reads or Server-Side Request Forgery (SSRF).
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` instances by calling `setFeature` to disable DTDs (`http://apache.org/xml/features/disallow-doctype-decl`, `true`), external general entities (`http://xml.org/sax/features/external-general-entities`, `false`), external parameter entities (`http://xml.org/sax/features/external-parameter-entities`, `false`), and loading external DTDs (`http://apache.org/xml/features/nonvalidating/load-external-dtd`, `false`). Additionally, set `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Each configuration must be wrapped in a `try-catch` block that logs the failure and securely throws an exception.
