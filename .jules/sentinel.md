## 2026-05-13 - Prevent XXE (XML External Entity) Vulnerabilities in XML Factories
**Vulnerability:** DocumentBuilderFactory and SAXParserFactory instances were created without properly disabling DTD processing or external entity resolution, exposing the application to XML External Entity (XXE) vulnerabilities during parsing of user-provided XML files or configurations.
**Learning:** Default factory instances like DocumentBuilderFactory.newInstance() do not have adequate XXE protections. Relying entirely on simple `.setValidating(false)` or similar methods is insufficient, as resolving entities via a system ID in a DOCTYPE declaration still remains permitted in standard parsers without specific features being disabled.
**Prevention:** Whenever initializing `DocumentBuilderFactory` or `SAXParserFactory`, explicitly disable 'disallow-doctype-decl', 'external-general-entities', 'external-parameter-entities', and 'load-external-dtd' features to fully prevent external entity resolution and DoS attacks related to XML parsing.
