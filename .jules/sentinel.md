## 2024-06-07 - XXE Vulnerability in ReaderUtils
**Vulnerability:** DocumentBuilderFactory and SAXParserFactory were instantiated without features to disable external entities, doctype declarations, and external DTDs, which can lead to XML External Entity (XXE) injection vulnerabilities.
**Learning:** XML parsers default configurations in Java often permit fetching of external entities, which can lead to SSRF or local file disclosure. The features must be explicitly disabled, each wrapped in an individual try-catch to ensure that if a parser implementation does not support one feature, the remaining features are still evaluated and the parser does not fail to apply security.
**Prevention:** Always explicitly set features to disable external entities (`http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`), doctype declarations (`http://apache.org/xml/features/disallow-doctype-decl`), and load-external-dtd (`http://apache.org/xml/features/nonvalidating/load-external-dtd`) when initializing XML parsers. For DocumentBuilderFactory, also use `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch generic exceptions to ensure broad compatibility and fail securely by throwing an exception if configuration fails.
