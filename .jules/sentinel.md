## 2024-05-18 - XXE Vulnerability in XML Parsers
**Vulnerability:** XML External Entity (XXE) vulnerability due to insecurely configured DocumentBuilderFactory in `RemoteDocumentReaderImpl.java`. The default configuration allows resolving external entities, which can lead to local file disclosure, SSRF, or DoS.
**Learning:** In Java, XML parsers like DocumentBuilderFactory and SAXParserFactory must be explicitly configured to prevent XXE. Simply setting `newInstance()` is not enough. The codebase contains multiple instances where XML parsers are instantiated without explicit feature flags to disable external entity resolution. The `RemoteDocumentReaderImpl` is a clear example of this.
**Prevention:** Always configure XML parsers with specific features to disable document type declarations, external general entities, external parameter entities, and load-external-dtd. Also, disable XInclude and expand entity references for `DocumentBuilderFactory`. Throw RuntimeExceptions upon parsing failures instead of logging and proceeding insecurely.
