## 2026-06-05 - Fix XXE in DocumentBuilderFactory
**Vulnerability:** DocumentBuilderFactory instantiation missing XXE protections (XML External Entity injection). Found in `RemoteDocumentReaderImpl.java` where `url.openStream()` parses external URLs into an XML Document.
**Learning:** By default, XML parsers in Java are vulnerable to XXE. They can read local files, probe internal networks, and trigger DoS (Billion Laughs attack) if standard features are not explicitly turned off.
**Prevention:** Always configure `DocumentBuilderFactory` explicitly with `setFeature("http://apache.org/xml/features/disallow-doctype-decl", true)`, `setFeature("http://xml.org/sax/features/external-general-entities", false)`, `setFeature("http://xml.org/sax/features/external-parameter-entities", false)`, `setFeature("http://apache.org/xml/features/nonvalidating/load-external-dtd", false)`, `setXIncludeAware(false)`, and `setExpandEntityReferences(false)` wrapped in proper try-catch blocks to prevent SAXNotRecognizedException/SAXNotSupportedException from stopping the application of other features.
