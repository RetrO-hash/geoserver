## 2026-05-02 - Fix XML External Entity (XXE) vulnerability in ReaderUtils
**Vulnerability:** DocumentBuilderFactory and SAXParserFactory instances in `org/geoserver/util/ReaderUtils.java` were not configured securely, exposing the application to XML External Entity (XXE) vulnerabilities during XML parsing and validation.
**Learning:** XML parsers in Java (like DocumentBuilderFactory and SAXParserFactory) default to insecure configurations that evaluate DOCTYPE declarations and external entities. Even if a utility class aims to simplify XML parsing, it must explicitly disable these features to be secure.
**Prevention:** Always explicitly disable DOCTYPE declarations (`http://apache.org/xml/features/disallow-doctype-decl`), external general entities, external parameter entities, and external DTDs when configuring `DocumentBuilderFactory` or `SAXParserFactory`. For `DocumentBuilderFactory`, also set `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch configuration exceptions securely and fail fast.
