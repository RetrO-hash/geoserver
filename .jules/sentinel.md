## 2024-10-24 - XXE Vulnerability in XML Parsers
**Vulnerability:** The application instantiates multiple `DocumentBuilderFactory` and `SAXParserFactory` instances without disabling external entities or DTDs, which can lead to XML External Entity (XXE) vulnerabilities when processing user-supplied XML documents.
**Learning:** Default configurations for Java XML parsers are often insecure and vulnerable to XXE. They must explicitly disable DTDs (`http://apache.org/xml/features/disallow-doctype-decl`) or external entities.
**Prevention:** Configure factories by setting the appropriate features: `setFeature("http://apache.org/xml/features/disallow-doctype-decl", true);`, `setFeature("http://xml.org/sax/features/external-general-entities", false);`, `setFeature("http://xml.org/sax/features/external-parameter-entities", false);`, `setFeature("http://apache.org/xml/features/nonvalidating/load-external-dtd", false);`, `setXIncludeAware(false);`, and `setExpandEntityReferences(false);`.
