## 2024-05-18 - Prevent XXE Vulnerability in XML Parsers
**Vulnerability:** DocumentBuilderFactory instances were configured without disabling external entities or DTDs, which can lead to XML External Entity (XXE) vulnerabilities when parsing untrusted metadata from remote URLs.
**Learning:** In Java XML parsers, security features must be explicitly set to disable DOCTYPE declarations, external general/parameter entities, and external DTD loading. XInclude and expandEntityReferences must also be disabled. Each setFeature call should be wrapped in a try-catch block to handle cases where a parser doesn't support a specific feature. In security-critical contexts, failing securely by throwing an exception (e.g., IOException) is the correct approach to prevent parsing with an insecure configuration.
**Prevention:** Always configure DocumentBuilderFactory and SAXParserFactory with the required security features wrapped in individual try-catch blocks. If a required security feature is not supported by the parser, fail securely and abort parsing.
