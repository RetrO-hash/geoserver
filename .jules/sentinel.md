## 2026-05-01 - Prevent XXE Vulnerabilities in ReaderUtils XML Parsers
**Vulnerability:** XML parsers `DocumentBuilderFactory` and `SAXParserFactory` in `ReaderUtils.java` were configured without explicitly disabling external entity processing (XXE), DOCTYPE declarations, and XInclude, which could allow attackers to perform SSRF or read local files when parsing untrusted XML.
**Learning:** Default XML parsers in Java are often vulnerable to XXE out-of-the-box. It is necessary to explicitly configure factory features to disable risky behavior for both DOM (`DocumentBuilderFactory`) and SAX (`SAXParserFactory`) parsing.
**Prevention:** Always configure XML parsers securely by setting features like `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd` to `false` or `true` appropriately. For `DocumentBuilderFactory`, also call `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Catch configuration exceptions and fail securely.
