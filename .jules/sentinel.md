## 2024-05-24 - [Fix XXE Vulnerability in XML Parsers]
**Vulnerability:** XML External Entity (XXE) vulnerability due to insecurely configured `DocumentBuilderFactory` and `SAXParserFactory` instances in `org.geoserver.util.ReaderUtils` and `org.geoserver.catalog.util.ReaderUtils`.
**Learning:** Default configurations for standard Java XML parsers (`DocumentBuilderFactory`, `SAXParserFactory`) are vulnerable to XXE. They must be explicitly configured to disallow DTDs and external entities.
**Prevention:** Always explicitly set secure features on `DocumentBuilderFactory` and `SAXParserFactory` instances. Specifically, set `http://apache.org/xml/features/disallow-doctype-decl` to `true`, and set `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd` to `false`. For `DocumentBuilderFactory`, also set `setXIncludeAware(false)` and `setExpandEntityReferences(false)`. Wrap the configuration in a `try-catch` block to handle `ParserConfigurationException` or `SAXNotRecognizedException` and fail securely.
