## 2024-07-01 - Missing XXE Prevention in XML Parsers
**Vulnerability:** XML External Entity (XXE) Injection vulnerability in `org.geoserver.util.ReaderUtils`. The methods `parse(Reader xml)` and `validate(...)` instantiate `DocumentBuilderFactory` and `SAXParserFactory` respectively without disabling external entity resolution, loading of external DTDs, and the document type declaration (`http://apache.org/xml/features/disallow-doctype-decl`).
**Learning:** Common utility classes that process XML documents from arbitrary sources must be configured securely. Relying on default XML parser configurations leaves the application susceptible to XXE attacks (reading arbitrary files, SSRF, DoS).
**Prevention:** Always configure `DocumentBuilderFactory` and `SAXParserFactory` to disable external entity features (`http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, `http://apache.org/xml/features/nonvalidating/load-external-dtd`) and use `setXIncludeAware(false)`/`setExpandEntityReferences(false)`. Catch and log configuration exceptions securely without exposing details.
