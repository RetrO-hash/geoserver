## 2026-04-30 - Fix XXE in ReaderUtils DocumentBuilderFactory and SAXParserFactory
**Vulnerability:** XML External Entity (XXE) injection was possible because `DocumentBuilderFactory` and `SAXParserFactory` used for XML parsing in `org.geoserver.util.ReaderUtils` were not configured to disallow doctype declarations or external entities.
**Learning:** Shared utility methods (`ReaderUtils.parse` and `ReaderUtils.validate`) that handle untrusted XML must explicitly disable DTDs (`disallow-doctype-decl`) and external entities. The fix involves setting specific features to `false`. Catch block must use general `Exception` as some implementations may throw different configuration exceptions. It is critical to enforce `setXIncludeAware(false)` and `setExpandEntityReferences(false)`.
**Prevention:** Always follow the OWASP XXE Prevention Cheat Sheet when configuring `DocumentBuilderFactory`, `SAXParserFactory`, and `XMLInputFactory`. Set `http://apache.org/xml/features/disallow-doctype-decl` to `true`.
