## 2026-05-14 - Fix XXE vulnerabilities in ReaderUtils
**Vulnerability:** DocumentBuilderFactory and SAXParserFactory in `ReaderUtils` were vulnerable to XML External Entity (XXE) injection due to missing secure configuration to disable external entities and DTDs.
**Learning:** In Java applications, when creating XML parsers using `DocumentBuilderFactory` or `SAXParserFactory`, external entity processing and document type declarations (DTDs) are often enabled by default, which can lead to XXE attacks.
**Prevention:** Always explicitly configure these factories to disable external entities and DTDs (e.g., set features like `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd` to secure values). Also, configure `setXIncludeAware(false)` and `setExpandEntityReferences(false)` for `DocumentBuilderFactory`. Catch `ParserConfigurationException` or `Exception` and fail securely.
