## 2026-05-05 - Fix XXE vulnerabilities in XML parsing
**Vulnerability:** External XML Entity (XXE) vulnerabilities found in `ReaderUtils.java` via `DocumentBuilderFactory` and `SAXParserFactory`. The factories lacked configuration to disable external general and parameter entities, as well as document type definitions (DTDs).
**Learning:** XML parsers instantiated via factories in Java must explicitly have dangerous features disabled because they are enabled by default. `setFeature` is required to disable `http://apache.org/xml/features/disallow-doctype-decl`, `http://xml.org/sax/features/external-general-entities`, `http://xml.org/sax/features/external-parameter-entities`, and `http://apache.org/xml/features/nonvalidating/load-external-dtd`.
**Prevention:** Always explicitly configure `DocumentBuilderFactory`, `SAXParserFactory`, and `XMLInputFactory` instances with the appropriate security settings to disable external entities and DTDs. Catch configuration exceptions and wrap them in a `RuntimeException` to fail securely without exposing sensitive internals.
